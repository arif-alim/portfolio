Review status: ServiceOntario and CBSA migrations authorized by the user on 2026-10-20. Hydro One and later project migrations still require separate authorization. The audit and extraction results below describe the earlier planning run.

Manulife is the completed reference implementation. Keep its four tabs, narrative, source artwork, frame order, lightbox behavior, plan configuration, member management and approvals. ## Scope of this run

Audited all 22 project routes, their current tab configurations, shared rendering components, referenced artwork and test coverage. Homepage, project listing, global navigation, global styles, original images and business-state logic remain unchanged.

## Architecture decisions

Use `PortfolioTemplate` and `SimpleLayout` for the compact title, introduction, metadata and page width. Keep the existing Headless UI `PortfolioTabs` for keyboard navigation, focus, selected-tab scrolling and panels. A second hero, tab system or page framework would duplicate working code.

Use the four Manulife section names as an editorial convention, not a requirement to render four tabs on every route:

- **Overview:** supported problem, users, role, approach, deliverables and outcomes. Include company context here. Feature one or two authentic visuals where approved assets support the story.
- **Design Process:** documented research, collaboration, constraints and decisions. Omit it when the available copy cannot sustain a distinct section.
- **Design Explorations:** permitted artifacts grouped by task or medium, with source labels, captions and enlargement. Omit it for confidential or unpublished work.
- **Interactive Demo:** an implemented, project-specific local reconstruction. Keep fictional records and rules distinct from original artifacts and production claims. Omit it until the demonstration exists.

A missing section should be absent from the tab configuration, not a disabled tab, empty panel or “coming soon” placeholder. Preserve meaningful subgroups such as Bombardier’s Lego Components and Craft City’s packaging work. Design Systems Engineering may retain its working technical article and anchor navigation instead of being forced into tabs.
